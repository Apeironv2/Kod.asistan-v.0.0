# Kod.asistan-v.0.0
Projenin Amacı
Bu projenin amacı, kullanıcıların günlük işlerini kolaylaştıran bir dijital asistan geliştirmektir. Asistan; hesaplama yapma, kullanıcıları selamlama ve basit soruları yanıtlama gibi görevlerde yardımcı olacaktır.

Özellikler
Selamlama: Kullanıcıya merhaba der ve ona uygun şekilde karşılık verir.
Hesaplama: Toplama, çıkarma, çarpma ve bölme işlemlerini yapar.
Basit Sohbet: Kullanıcının temel sorularına yanıt verir.
Günlük Yardım: Kullanıcının günlük işlerini daha hızlı ve kolay yapmasına yardımcı olur.
Kullanıcı Dostu Arayüz: Kolay anlaşılır ve kullanımı basit bir yapıya sahip olur.

Kullanılan Teknolojiler
Python
Git ve GitHub
